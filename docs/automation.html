Automation

arc embeds a high-speed local automation bridge: a localhost TCP server that exposes the full internal command surface to external scripts, AI coding agents, and automation workflows.

The Automation Bridge

On startup, arc binds a local TCP server on 127.0.0.1:3987. Commands received over this bridge are dispatched directly through the same command engine powering the UI, ensuring that:

  • Every change is recorded on the non-destructive undo/redo history stack.
  • All registered Lua plugin hooks fire consistently.
  • The 3D WebGL viewport and project trees re-render in real time.

bridge.json and Auth

To secure local access, arc generates a unique authentication token upon launch and writes it to bridge.json in the user configuration directory:

SettingDetails

Protocol

After handshake, exchange newline-delimited JSON commands over the TCP socket: 

// Client request (one JSON object per line)
{"id":"1","cmd":"get_state","params":{}}
{"id":"2","cmd":"create_entity","params":{"document_id":"doc-1","geometry":{"type":"box","width":60,"height":20,"depth":60}}}

// Server response
{"id":"1","ok":true,"result":{"active_document_id":"doc-1"}}
{"id":"2","ok":true,"result":{"id":"ent-1","name":"Box 1"}}

MCP Stdio Client

The bundled crates/arc-mcp tool provides a standard Model Context Protocol (MCP) server over stdio. This enables AI assistants (Antigravity CLI, Claude Desktop, Cursor, IDE agents, and autonomous CLI tools) to model, inspect, and manipulate 3D scenes in Arc with zero friction.

AI Agent Design Principles

  • Automatic Document Resolution: Agents never need to juggle document IDs. Omitting document_id automatically operates on the active document or seamlessly creates a new project.
  • Direct High-Level Primitives: Call arc_create_box, arc_create_cylinder, arc_create_sphere, or arc_create_extrude with positions, Euler angle rotations (in degrees), and human color names or hex codes in a single tool call.
  • Constructive Solid Geometry (CSG): Apply boolean unions, differences (cutouts/holes), and intersections with arc_boolean.
  • Atomic Multi-Operation Batches: The arc_batch tool lets agents define entire complex assemblies (e.g., 20 parts with cutouts and standoffs) in a single turn using $alias variable references between steps.
  • Context-Friendly Inspection: arc_inspect_scene returns a clean, compact summary of scene entities without dumping megabytes of vertex floats into the LLM context window.

Configuration

Antigravity CLI (~/.gemini/config/mcp_config.json):

{
  "mcpServers": {
    "arc": {
      "command": "/path/to/arc/target/release/arc-mcp"
    }
  }
}

Claude Desktop / Workspace (.mcp.json):

{
  "mcpServers": {
    "arc": {
      "command": "cargo",
      "args": ["run", "--quiet", "--release", "--bin", "arc-mcp"]
    }
  }
}

One-Turn Assembly with arc_batch

An AI agent can construct an entire multi-part assembly with holes in a single turn:

{
  "operations": [
    {
      "alias": "base",
      "tool": "create_box",
      "args": { "width": 100, "depth": 100, "height": 10, "color": "steel", "name": "base_plate" }
    },
    {
      "alias": "hole",
      "tool": "create_cylinder",
      "args": { "radius": 10, "height": 30, "position": [0, 5, 0], "name": "center_hole_tool" }
    },
    {
      "tool": "boolean",
      "args": { "operation": "difference", "first_id": "$base", "second_id": "$hole" },
      "alias": "plate_with_hole"

Raw Socket Example

Python script demonstrating direct programmatic modeling via localhost TCP: 

import json, socket, pathlib

info = json.loads(pathlib.Path("~/.local/share/com.arc.cad/bridge.json").expanduser().read_text())
sock = socket.create_connection(("127.0.0.1", info["port"]))
f = sock.makefile("rw", encoding="utf-8", newline="\n")

# Authenticate
f.write(json.dumps({"auth": info["token"]}) + "\n")
f.flush()
assert json.loads(f.readline()).get("ok")

def send_cmd(req_id, cmd, **params):
    f.write(json.dumps({"id": str(req_id), "cmd": cmd, "params": params}) + "\n")
    f.flush()
    return json.loads(f.readline())

state = send_cmd(1, "get_state")["result"]
doc_id = state["active_document_id"]

# Place a parametric 3D box
res = send_cmd(2, "create_entity", document_id=doc_id,
               geometry={"type": "box", "width": 100, "height": 40, "depth": 60})
print("Created solid entity:", res)
