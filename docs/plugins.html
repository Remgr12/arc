Plugins

arc is extensible with Lua. Each .lua file in a plugin directory is one plugin: it registers lifecycle hooks and talks to the open document through the arc API.

How plugins work

A plugin is a single Lua file. Its file stem (the name without .lua) is the plugin's name. On startup, and whenever you hit Reload, arc discovers every .lua file in its plugin directories, evaluates each once, and records any hooks it registers. If two plugins have the same name (same file stem), the first one found wins. Plugins run in their own Lua state, so editor commands never block on plugin code.

Plugin directories

arc looks for plugins in two places (first match per name wins):

  • Next to the executable: a plugins folder in the same directory as the arc binary.
  • App data directory: plugins inside the per-user app data dir (e.g. %APPDATA%/arc/plugins on Windows).
When running a development build (cargo tauri dev), the src-tauri/plugins directory of the repository is searched as well.

Enabling plugins

Everything is managed in Settings → Plugins: each discovered plugin gets a row with a checkbox to enable or disable it, and an ok or error status (hover a row to see the load error). Hit Reload to re-read every plugin directory after you change files on disk. Only enabled plugins fire their hooks.

Lifecycle hooks

Register a hook with arc.on(event, fn). Four events exist; the table shown is the payload passed to the function:

hook events
EventWhen it firesPayload
startonce when arc starts up and plugins are loadedempty
newa new document is createdempty
opena document is opened from disk{ path }
savea document is saved{ path }

Registering a hook with any other event name raises an error, which shows on the plugin's status row.

The arc API

The arc global table exposes the editing API:

arc.*
FunctionReturnsDescription
on(event, fn)noneRegister a lifecycle hook (see events above).
log(msg)noneWrite a line to the application log.
active_document()id or nilThe id string of the active document, or nil when none is open.
entities()arrayList of { id, name, kind, position, visible } for every entity in the active document.
add_entity(geometry, name?)idCreate an entity from a geometry table (or a JSON string) and an optional name; returns the new entity id.
raycast(origin, direction, tolerance?)hit or nilRaycast from origin along direction (two number arrays) against the active document; tolerance defaults to 1. Returns { entity_id, point, normal, distance }.
set_transform(id, transform)noneSet the full transform of one entity; recorded in undo history.
undo()label or nilUndo the last operation in the active document.
redo()label or nilRedo the last undone operation.
Calling these without an active document raises "no active document". Geometric values are scene-space: position, point, and normal are { x, y, z }-style number arrays.

Examples

This plugin stamps a small box into every new document, logs what happens on open and save, and shows a transform edit plus raycast: 

-- plugins/stamper.lua

-- One box in every new document (undoable, like any edit)
arc.on("new", function()
  local id = arc.add_entity({ type = "box", width = 60, depth = 40, height = 20 }, "Plugin box")
  arc.log("created " .. tostring(id))
end)

-- Tell the log what got opened or saved
arc.on("open", function(p)
  arc.log("opened " .. p.path)
end)

arc.on("save", function(p)
  arc.log("saved " .. p.path .. ", " .. #arc.entities() .. " entities")
end)

-- Also run once at startup
arc.on("start", function()
  arc.log("stamper loaded")
end)

A transform edit and a raycast, against the active document:

local id = arc.active_document()
if id and #arc.entities() > 0 then
  local e = arc.entities()[1]

  -- set_transform takes a full transform: position, quaternion
  -- rotation (x, y, z, w) and scale; it is undoable.
  arc.set_transform(e.id, { position = { 0, 0, 0 }, rotation = { 0, 0, 0, 1 }, scale = { 1, 1, 1 } })

  -- cast a ray straight down and report the first hit
  local hit = arc.raycast({ 0, 100, 0 }, { 0, -1, 0 })
  if hit then
    arc.log("ray hit " .. tostring(hit.entity_id) .. " at distance " .. hit.distance)
  end
end
