Plugins

arc provides a sandboxed Lua engine for automating modeling tasks, creating custom parametric generators, and hooking into document lifecycle events.

How Plugins Work

Each plugin is a standard .lua script. On startup or when hitting Reload Plugins, arc evaluates every script and registers its lifecycle hooks. Plugins run in an isolated Lua runtime, keeping the interactive viewport fluid and responsive.

Plugin Directories

arc searches for plugins in two locations:

  • Next to the application executable: A plugins/ directory adjacent to the binary.
  • User app data directory: A plugins/ directory in your user profile (e.g., ~/.config/arc/plugins on Linux or %APPDATA%/arc/plugins on Windows).

Managing Plugins

Open Settings → Plugins to view all detected scripts, toggle them on or off, and inspect execution logs or syntax errors. Enabled plugins run automatically on their registered events.

Lifecycle Hooks

Register event handlers using arc.on(event, callback):

Available Events
EventTriggerArgument
startFires when arc initializes and plugins loadNone
newFires when a new document is createdNone
openFires when a document is opened from disk{ path }
saveFires when a document is saved{ path }

The arc Lua API

arc API Methods
FunctionReturnsDescription

log(message)nonePrint a message to the arc application console.
active_document()id or nilReturn the active document ID.
entities()arrayList all entities in the active document.

Examples

A sample script that automatically logs events and generates a parametric mounting plate: 

-- plugins/mounting_plate.lua

arc.on("new", function()
  local plate = arc.add_entity({
    type = "box",
    width = 100,
    depth = 60,
    height = 10,
    corner_radius = 2
  }, "Mounting Plate")

  arc.log("Created base plate: " .. tostring(plate))
end)

arc.on("save", function(doc)
  arc.log("Document saved to: " .. doc.path)
end)
