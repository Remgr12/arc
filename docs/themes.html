Themes

A theme is a flat set of hex colors: a ten-step neutral scale, three accent steps, and three viewport colors. Built-ins ship in code; your own themes are simple JSON files you can import, export, and share.

Built-in themes

Built-ins are selected and switched in Settings → Appearance:

built-in themes
ThemeLook
GraphiteNeutral dark grays with a blue accent. The default theme.
MidnightDeep blue-navy panels with a bright blue accent.
ForestDark green panels with a green accent.
BlueprintLight blue-gray paper look — like drafting paper.
PaperWarm light cream tones with a burnt-orange accent.

The viewport reacts to the theme too: background, grid, and the view cube adopt theme colors, and viewports with a light background switch to a light-mode cube.

Color keys

A theme defines exactly these sixteen keys:

THEME_COLOR_KEYS
KeyUsed for
base-50Deepest background (window background in dark themes).
base-100Base surfaces: panels and dialogs.
base-150Slightly raised surfaces, control backgrounds.
base-200Fills — hover and control states.
base-300Deeper fills and pressed states.
base-400Borders between regions and controls.
base-500Faint text and placeholders.
base-600Secondary text.
base-700Primary text.
base-800Brightest text and highlights.
accent-500Accent highlights (selection, view cube hover on dark viewports).
accent-600Main accent for buttons and active controls.
accent-700Deeper accent for pressed and contrast states.
viewport-bg3D viewport background.
viewport-gridPrimary viewport grid color.
viewport-grid-lineSecondary viewport grid line color.

Theme JSON

A theme file is JSON with a name and a colors object, where every value is a CSS color: 

{
  "name": "My theme",
  "colors": {
    "base-100": "#131313",
    "base-800": "#e8e8e8",
    "accent-600": "#00a0dd",
    "viewport-bg": "#0c0c0e"
  }
}

More rules make files forgiving to write:

  • A flat file without the wrapper works too — colors at the top level, with name alongside them.
  • A few shorthand aliases are accepted: accent → accent-600; background, bg, viewport, canvas, theme → viewport-bg; grid → viewport-grid; grid-line, gridline → viewport-grid-line.
  • Missing keys fall back to the default theme (Graphite), so you can theme just one part.
  • Unknown keys are ignored.
  • Colors may be any CSS form — #abc, #aabbccdd, rgb(...) — and are normalized; unrecognized colors make the import fail with the offending key named.

Import and export

In Settings → Appearance, import a theme JSON file to add it to your themes — importing is instant and the theme applies immediately. Re-importing a file with the same name creates a fresh entry. Exporting a theme writes the wrapped JSON format above, pretty-printed, ready to share. Your custom themes and the active selection are stored with your profile data (in the app's web storage) and survive restarts.
