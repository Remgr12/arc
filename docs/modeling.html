Modeling

Sketch on the ground plane, spin or place profiles like building parts, and edit everything in place. Every step of the way back is kept.

Primitives

Pick a primitive from the palette (or its key) and click a point on the ground plane to place it. Primitives are parametric: their parameters stay editable in the Properties panel afterwards.

Sketch tools

Sketch tools draw on the ground plane with grid snapping (see Navigation). Line, polyline, dimension, and wall tools collect more than one point before finishing.

sketch tools
ToolKeyBehavior
CircleGDraw a circle outline (radius 40, 48 segments by default).
LineLDraw a line between two points.
PolylineJClick to add points; double-click to finish.
RectangleRDraw a rectangle outline (80 × 50 by default).
DimensionDAnnotate the distance between two points.
WallHDraw a wall along a path (10 wide, 80 tall by default); double-click to finish.

Select and move

  • Select (V): select and inspect entities in the viewport.
  • Move (M): drag entities along the ground plane.
  • Select all: Ctrl A; Duplicate: Ctrl D; Delete selection: Delete or Backspace.
  • Explode selection: available from the command palette (Ctrl K); it has no default key.
  • Double-click an entity to zoom the camera to it.

Layers

The Project panel has a Layers tab beside the scene outline. Add layers with the + button; each layer has a color, and can be toggled visible and locked. Any entity can override its layer's settings with per-entity visibility, lock, and color.

Properties

With something selected, the Properties panel below the Project panel shows its editable parameters: geometry dimensions, transform position, rotation and scale, visibility, and so on. Edit a value and the change applies immediately. Entities without editable parameters say so.

Undo and redo

Every editing operation is recorded as a reversible command, including changes made by Lua plugins. Ctrl Z undoes and Ctrl Shift Z (or Ctrl Y) redoes; the history is per document.

Documents

arc works on several documents at once; each open document gets a tab in the top bar and switching between them is live. Documents carry their undo history with them.

file actions
ActionBindingNotes
New documentCtrl NOpens an empty Untitled n document.
Open…Ctrl ONative .arc files (plain JSON).
SaveCtrl SSaves to the document's path; asks for one when the file has none.
Save As…noneNo default binding; use File menu or the command palette.
Export modelCtrl E.obj (text OBJ) or .stl (binary STL).

The File menu also lists up to five recently opened files. With Reopen last session at launch enabled, up to six recent documents are reopened on startup (most recent last, so it ends up active), see Getting started.
