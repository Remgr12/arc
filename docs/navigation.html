Navigation

The viewport is mouse-driven: you are never locked out of the camera, and every orientation has a one-click shortcut on the view cube.

The view cube

The top-right corner of the viewport holds a small 3D cube that mirrors the current camera orientation — as you orbit, the cube rotates with you. Its faces are labeled TOP, BOTTOM, FRONT, BACK, LEFT, and RIGHT.

  • Hover a face to highlight it (the highlight uses the theme accent color).
  • Click a face to focus that plane — the camera snaps into a straight-on view of it.
  • Drag on the cube itself (not a face) to orbit the scene. A click only counts if you release on the same face without moving more than a few pixels.

The cube picks up its colors from the active theme (Themes): in light viewports it uses accent-600 for hover, in dark ones accent-500.

Grid and snapping

Sketch and placement tools draw on the ground plane against a grid. Drafting points snap to the grid, so clicks land on exact coordinates.

All of this lives in Settings → General:

  • Grid size — the spacing between grid points (a positive number, editable in place).
  • Snap to grid — enable or disable snapping; the status bar shows a snap indicator while it is on.
  • Show grid / Show axes — toggle the viewport overlays.

The current grid size and the snap state are also visible in the status bar at all times.

Units

arc supports two unit systems, selectable in Settings → General: Metric (cm) — the default — or Imperial (in). The unit system determines how grid size is labelled and interpreted; the status bar shows it in the active unit (cm in metric, inches in imperial).
