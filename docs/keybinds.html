Quick Action Keys

  • Enter: Commits the active tool or confirms vertex placement.
  • Esc: Cancels the active tool, closes menus, or clears the current selection.
  • Shift: While using Line, polyline, or rectangle, locks drawing to 45° / 90° orthogonal constraints.

Customizing Keybind Profiles

Open Settings → Keyboard to configure keybindings:

  • Create Profiles: Duplicate the built-in Classic profile to create custom presets for blender-style or CAD-standard workflows.
  • Live Capture: Click any command shortcut field and press your desired key combination to record it instantly.
  • Conflict Detection: Highlights any duplicate shortcut assignments automatically.
