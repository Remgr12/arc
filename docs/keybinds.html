Keybinds

Every tool sits under one key so tools are picked without leaving the drawing. Bindings are stored as named profiles you can edit, share, and switch between.

Profiles

A keybind profile maps every action (tools plus file, edit, view, and app commands) to one or more key bindings, written canonically as ctrl+shift+z, delete, b, or f5. arc ships one built-in profile, Classic, which contains the default layout below. Your own profiles are stored in your profile data and survive restarts.

Fixed behavior, not part of profiles: Esc always closes the command palette or clears the current selection, even while typing in a field. Save As…, Explode selection, and Reload plugins have no key in the Classic profile — use the command palette (Ctrl K) or the File menu.

Mouse bindings

Mouse navigation is fixed: middle-drag orbits, right-drag pans, the wheel zooms, and double-clicking an entity zooms to it — see Navigation. The view cube also supports click-to-focus and drag-to-orbit.

Customizing

Open Settings → Keyboard (Ctrl ,). There you can:

  • Create and switch profiles; a new profile starts as a copy of the currently active one.
  • Rename profiles or delete them (the built-in Classic profile cannot be deleted).
  • Rebind any action with a live capture field: press the new key combination and it is recorded, modifiers included.
  • Assign multiple bindings to one action — for example Redo has both Ctrl Shift Z and Ctrl Y by default.
  • Reset a profile back to the Classic defaults at any time.

Conflicts inside a profile are detected: if a key is already taken by another action, arc tells you which action owns it. The Help menu in the top bar shows a live list of the keybinds of the active profile.
