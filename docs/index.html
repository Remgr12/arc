arc documentation

arc is an open-source 3D modeling application for design, architecture, and interiors, with a mesh-based geometry kernel written in Rust and native apps for Windows, macOS, and Linux. These pages cover how to install it and how everything works.

01Getting started Install a prebuilt bundle or compile from source, then a guided tour of the window: top bar, tool palette, panels, and status bar. 02Modeling Primitives, sketch tools, select and move, layers, property editing, undo/redo, and working with .arc documents. 03Navigation Orbit, pan, and zoom; the view cube; grid and snapping; units and grid-size settings. 04Keybinds The default Classic profile, every default binding in one table, and how to rebind in Settings → Keyboard. 05Plugins The Lua plugin system: lifecycle hooks, the arc API, plugin directories, and examples. 06Themes Built-in themes, importing and exporting theme JSON, and all sixteen color keys. 07Automation The local automation bridge: JSON commands over bridge.json, the handshake, command surface, and the bundled MCP stdio client.

About the app

arc is a multi-platform 3D modeling application built around a Rust kernel (arc-core) that owns the document, entities, layers, history, and mesh generation. The interface is React; the two sides talk through typed Tauri commands. The workflow is draft-first: sketch on the ground plane, place primitives like building parts, and adjust parameters in place.

Documents use a native .arc format (plain JSON) with OBJ and binary STL export. Everything else — keybind profiles, themes, Lua plugins — is designed to be customized and shared.

Source and downloads live at github.com/Remgr12/arc; prebuilt bundles are on Releases. arc is dual-licensed under MIT or Apache-2.0 at your option.
