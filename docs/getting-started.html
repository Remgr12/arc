Getting Started

Install prebuilt binaries or build arc from source, then explore the modern CAD interface.

Install

Prebuilt installers are published on GitHub Releases: MSI and NSIS installers for Windows, universal DMG for macOS, and AppImage, DEB, RPM, and Flatpak for Linux.

On Linux, you can also install via the official arc Flatpak repository:

# Add the arc Flatpak remote
flatpak remote-add arc https://remgr12.github.io/arc/flatpak-repo

# Install the application
flatpak install arc com.arc.cad

Build from Source

Prerequisites: Node.js 20+ with npm, and the Rust toolchain via rustup.

git clone https://github.com/Remgr12/arc.git
cd arc

# Install frontend dependencies
cd frontend && npm install && cd ..

# Launch in development mode
cargo tauri dev

To generate an optimized production bundle: 

cd frontend && npm run build && cd ..
cargo tauri build

First Launch

On first launch, arc creates an empty document ready for drafting. If Reopen last session at launch is enabled in Settings → General, your previous working documents reopen automatically.

Custom themes can be selected under Settings → Appearance, and keybinding profiles under Settings → Keyboard.

UI Tour

The workspace is organized into streamlined, non-intrusive CAD regions:

  • Top Navigation Bar: Contains the File, Edit, and View menus (for quick toggling of tool docks, inspector panels, and axes), a quick command search input (Type a tool or command), and document tabs for switching between open files.
  • Shapr3D Left Dock: A modern collapsible and resizable tool dock arranged into clean categories:
    • Sketch: Line (L), Polyline (J), Rectangle (R), Circle (C), Arc (A), Polygon (N).
    • Construct: Box (B), Sphere (G), Cylinder (Q), Cone (Z), Torus (Y), Plane (P).
    • Tools: Extrude (E), Revolve (W), Sweep (S), Loft (K), Fillet (F), Offset (O), Mirror (I), Trim (T), Extend (X).
    • Transform: Select (V), Move (M), Rotate, Scale.
    • Inspect: Dimension (D), Wall (H).
    • Settings & Docs: Fast access to application preferences and guides.
    Can be resized horizontally or collapsed completely to maximize modeling real estate.
  • 3D Canvas Viewport: Full-screen WebGL viewport with infinite X/Y/Z coordinate axes. The drafting grid stays hidden during normal viewing and automatically fades in when you initiate a sketch or placement tool.
  • Viewport Controls (Top Right): Interactive 3D ViewCube for one-click plane snapping and orbiting; display mode selector (Solid, Shaded, Wireframe, X-Ray); Screenshot capture; Undo/Redo History toggle; Magnet/Snapping toggle; and Unit indicators.
  • Selection HUD (Floating Bottom Bar): Context-aware pill bar that appears when geometry is selected, offering immediate one-click actions for Extrude, Fillet, Move, Delete, and committing or canceling via Enter or Esc.
  • Right Inspector Panels: Contains the Project panel (hierarchical scene tree of solid bodies and sketches), Layers manager (visibility, locking, and color overrides), and the Properties inspector.
Tip: Press Esc or Enter at any time to commit or deselect an active modeling tool. Press Ctrl+K to launch the command palette from anywhere.
