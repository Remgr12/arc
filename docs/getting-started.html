Getting started

Download a prebuilt bundle or compile arc yourself, then take a quick lap around the interface.

Install

Prebuilt bundles are on GitHub Releases: installers for Windows (MSI, NSIS), macOS (DMG), and Linux (AppImage, DEB, RPM, Flatpak).

On Linux, arc is also published as a Flatpak repository hosted on this website:

# add the arc repository
flatpak remote-add arc https://remgr12.github.io/arc/flatpak-repo

# install
flatpak install arc com.arc.cad

Build from source

Prerequisites: the Rust toolchain via rustup, and Node.js 20+ with npm.

git clone https://github.com/Remgr12/arc.git
cd arc

# frontend deps
cd frontend && npm install && cd ..

# run in development mode
cargo tauri dev

For a production build, build the frontend first (the bundler does not run it for you), then build the app: 

cd frontend && npm run build && cd ..
cargo tauri build
For platform matrix builds use scripts/build.sh; pushing a tag runs scripts/release.sh in CI; the flatpak directory contains the Flatpak manifest.

First launch

The editor needs an active document to be usable, so arc creates one for you: on the very first launch (and any time no document remains) you start with an empty Untitled 1 document ready to draw in.

If Reopen last session at launch is checked in Settings → General (the default session restore reopens up to six recent documents, most recent last so it ends up active), your previous documents come back where you left them.

Themes live under Settings → Appearance, keyboard profiles under Settings → Keyboard — see Keybinds and Themes.

The first run also asks for a projects folder — it is where the startup screen lists your .arc project files, lets you sort them by name, date, or size, and offers a New project button. You can change the folder later from the startup screen or open the app without it.

Updates. arc checks GitHub Releases for a new version when you start it, but never more often than every 12 hours. If one is found you get a window with the version and release notes and can install it with one click — the update downloads and arc restarts. You can also check manually under Settings → General → Check for updates. Flatpak installs and system packages (deb/rpm) are skipped: they are updated by the Flatpak CLI or your package manager instead.

UI tour

The window is arranged in five regions:

  • Top bar — the arc logo, the File menu (New document, Open…, Save, Save As…, Export model, and up to five recent files with their keybind hints), document tabs for switching between every open document, and a Help menu that lists all keybinds.
  • Tool dock — a floating panel on the left with one button per tool, grouped into Tools (Select, Move), Create (box, sphere, cylinder, cone, torus, plane), and Sketch tools (sketch mode, circle, line, polyline, rectangle, dimension, wall). Drag its header to move it, grab the bottom-right corner to resize it, and double-click the header (or use the chevron) to fold it into a small floating pill. Every tool also sits under a single key — see Keybinds.
  • Viewport — the WebGL scene where you draw and view your model. The view cube in the top-right corner mirrors the camera orientation; see Navigation.
  • Right panel — the Project panel on top (a tabbed outline of the scene's entities and the document's layers, switchable to Layers), and the Properties panel below it for the current selection.
  • Status bar — a thin strip at the very bottom showing the current grid size in the active units (cm in metric, inches in imperial), a snap indicator when snapping is on, and the current status message.

The Ctrl K command palette is available anywhere and can launch any tool or command; press Esc to close it or clear the current selection.
