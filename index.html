0104

Built for fluid creation

Every tool is designed to feel natural and immediate. No modal roadblocks, no deep nested dialog trees. Sketch on any plane, convert closed curves to extrudable faces, and sculpt solids directly in 3D.

01

Parametric Primitives

Box, sphere, cylinder, cone, torus, and ground plane. Placed with exact dimensions and fully adjustable in the properties dock.

02

Direct 2D Sketching

Lines, polylines, circles, arcs, and rectangles. Connecting endpoints automatically creates planar faces ready for immediate extrusion.

03

Solid & Face Operations

Extrude, revolve, sweep, loft, fillet corners, offset profiles, and trim edges to build watertight solid bodies.

04

Infinite 3D Coordinate Canvas

Uncluttered canvas with infinite X/Y/Z coordinate axes. The drafting grid activates automatically when sketching or placing shapes.

05

Modern Floating Docks

Shapr3D-inspired left dock, top navigation bar, floating selection HUD, and an interactive 3D ViewCube for quick camera alignment.

06

Multi-Format CAD Interop

Standard STEP (B-rep) export/import, binary STL for 3D printing, and text OBJ files. Documents save in transparent native JSON.

0204

High-performance architecture

A clean separation between interface, communication, and geometry computation. The WebGL frontend renders at high frame rates while the Rust kernel handles solid geometry and STEP serialization.

USER INTERFACE React · Zustand · Three.js

WebGL viewport, transform gizmos, Shapr3D docks, customizable themes, and selection HUD.

Tauri 2 · Typed IPC
GEOMETRY KERNEL Rust Engine (truck B-rep)

Documents, layers, undo/redo history, B-rep solids, boolean operations, tessellation, and STEP parsing.

Lua · Sandboxed
EXTENSIONS Lua Plugins & Bridge

Automate workflows, generate parametric forms, or control arc externally via the local JSON bridge.

0304

Scriptable with Lua

Drop a Lua script into your plugins directory. Hook into document events or run custom algorithms to generate complex shapes, automate repetitive tasks, and inspect models.

0404

Quickstart & Installation

Get started with arc in seconds. Install prebuilt binaries for your operating system or compile from source.

Prebuilt Packages

Download installers directly from GitHub Releases. Includes MSI and NSIS for Windows, universal DMG for macOS, and AppImage, DEB, and RPM for Linux.

Built-in auto-updater notifies you when a new release is available.
