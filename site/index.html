arc

A modern, open-source 3D modeling application for design, architecture, and interiors, built around a mesh-based geometry kernel written in Rust.

01 · Modeling

Everything you need, nothing you don't

A focused toolset that covers general design, architecture, and interior workflows and stays out of your way.

primitives

Primitive modeling

Box, sphere, cylinder, cone, torus, and plane primitives with fully editable parameters.

sketch

Sketch tools

Circle, line, polyline, rectangle, dimension, and wall drawing on the ground plane with grid snapping.

solids

Solid generation

Extrude, revolve, sweep, and loft 2D profiles into watertight solids.

architecture

Architecture tools

Walls, stairs, slabs, roofs, columns, beams, doors, and windows.

layers

Layers

Visibility, locking, colors, and per-entity overrides.

history

Undo and redo

Full command history with every editing operation, so nothing is a dead end.

documents

Multi-document

Work on several documents at once with live switching.

export

File formats

Native .arc (JSON) documents plus OBJ and binary STL export.

02 · Engine

Rust kernel, Tauri shell, three.js viewport

A typed document and entity model with layers, selection state, and undoable command history lives in arc-core. Geometry compiles to triangle and line buffers, raycast picking operates directly on the meshes, and scene updates stream to a WebGL viewport over IPC.

arc-core

Mesh generation, winding, raycast picking, documents, layers, history, all in Rust.

Tauri 2

~30 typed IPC commands map every frontend action onto the kernel.

React + three.js

Zustand-driven one-way data flow into a live WebGL scene with selection and hover highlighting.

03 · Quick start

Download or build in a minute

Grab a prebuilt bundle from GitHub Releases, install via Flatpak, or compile from source.

# Build from source
git clone https://github.com/Remgr12/arc.git
cd arc

# frontend deps + build
cd frontend && npm install && npm run build && cd ..

# run in dev mode, or build for release
cargo tauri dev
cargo tauri build
# Linux: add the arc flatpak repository
flatpak remote-add arc \
  https://remgr12.github.io/arc/flatpak-repo

# install
flatpak install arc com.arc.cad

04 · Extend

Plugins in plain Lua

Drop a Lua file into a plugin directory and hook into the app's lifecycle. The arc API exposes entities, transforms, raycasting, and history.

arc.on("new", function()
  local id = arc.add_entity({ type = "box", width = 60, depth = 40, height = 20 }, "Plugin box")
  arc.log("created " .. tostring(id))
end)
