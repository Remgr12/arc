arc

A 3D modeling app for design, architecture, and interiors. Rust geometry kernel, native on Windows, macOS, and Linux — free and open-source.

Modeling

One toolset, no spring-loaded distractions

Sketch on the ground plane, spin profiles into solids, and place them like building parts. Walls snap, dimensions draw themselves, and every step of the way back is kept.

primitivesBox, sphere, cylinder, cone, torus, plane — parametric and editable in place.
sketch toolsCircle, line, polyline, rectangle, dimension, and wall drawing with grid snapping.
solidsExtrude, revolve, sweep, and loft two-dimensional profiles into watertight solids.
architectureWalls, stairs, slabs, roofs, columns, beams, doors, and windows as real parts.
layersVisibility, locking, and colors, with per-entity overrides.
historyEvery operation is a reversible command; full undo and redo.
documentsSeveral open at once, switching live.
formatsNative .arc documents are plain JSON; OBJ and binary STL export.
Built

A small, legible stack

The viewport never owns a copy of the truth. React draws the UI, arc-core owns the document, and typed messages bridge the two.

frontendReact · Zustand · three.jsWebGL scene, picking, drafting tools, themes.
ipcTauri 2, ~30 typed commandsEvery editing action crosses as a typed call.
kernelarc-core, RustDocument, entities, layers, history, mesh generation.
Keyboard

Draft at the speed of the alphabet

Every tool sits under one key, so tools are picked without leaving the drawing. Bindings are profiles you can edit and share.

Plugins

Extend with Lua

Drop a Lua file into the plugin directory. It fires on start, new, open, and save, and talks to the document through the arc API — entities, transforms, raycasting, history.

arc.on("new", function()
  local id = arc.add_entity({ type = "box", width = 60, depth = 40, height = 20 }, "Plugin box")
  arc.log("created " .. tostring(id))
end)
Quick start

Download or compile

Prebuilt bundles on GitHub Releases (MSI, NSIS, DMG, AppImage, DEB, RPM, Flatpak), or build it yourself.

build from source$
# frontend deps + build
git clone https://github.com/Remgr12/arc.git
cd arc/frontend && npm install && npm run build && cd ..

# dev mode, or a release build
cargo tauri dev
cargo tauri build
linux · flatpak$
# add the arc repository
flatpak remote-add arc \
  https://remgr12.github.io/arc/flatpak-repo

# install
flatpak install arc com.arc.cad
